# Python-3D-Flight-Simulator（Web 改造版）

这个仓库已改造成纯前端网页游戏版本，无需 Python 图形环境，直接在浏览器中运行。

## 启动方式

在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

- <http://localhost:8000>

## 操作说明

- `W / S`：控制机头上仰 / 下压
- `A / D`：控制飞机左 / 右滚转（横向位移）
- `↑ / ↓`：增减油门
- `Space`：开始或重新开始

## 玩法

- 穿过黄色光环获得分数。
- 躲避红色障碍物，碰撞即失败。
- 飞完整段航线即胜利。
